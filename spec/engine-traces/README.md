# Shared engine trace fixtures

Generated by `pathland-engine-golden` from the canonical Rust engine. Do not
edit the `.plpl.hex` files by hand.

Each file is one self-contained PLPL batch (opcodes + frame string table) in
lowercase hex. `#` lines are metadata/comments.

- Scenario semantics: [`../ENGINE.md`](../ENGINE.md)
- Regenerate: `cd lib/rust && cargo run -p pathland-engine-golden -- --emit`
- Verify: `cd lib/rust && cargo run -p pathland-engine-golden -- --check`
- JVM comparison: `EngineTraceTest` in `lib/java/pathland-view-kotlin`
