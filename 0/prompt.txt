You are refactoring the Pathland Java DSL library at `lib/java/pathland-view/src/main/java/com/pathland/view/` (plus `router/`). This is a precise mechanical change. The goal: (A) add single-value `with(...)` shortcuts to eligible types, and (B) REMOVE every view/modifier construction `.of(...)` factory. A helper already exists:

`com.pathland.view.Configurators` (package-private):
```java
static <V extends View & Configurable<C>, C extends View.Config> ViewBuilder<V, C> view(Supplier<C> config, Function<C, V> ctor, Consumer<C> setter)
static <M, C> M modifier(Supplier<C> config, Function<C, M> ctor, Consumer<C> setter)
```
Use it: `public static ViewBuilder<Text, Config> with(String text) { return Configurators.view(Config::new, Text::new, c -> c.text(text)); }`. For modifiers: `public static Padding with(float uniform) { return Configurators.modifier(Config::new, Padding::new, c -> c.uniform(uniform)); }`.

## A. Add shortcuts (raw + Signal overloads where the Config has both). Keep the existing `with(Consumer<Config>)` and `modifiers(...)` methods unchanged.

Eligible — **single-value views** (primary member → shortcut):
- `Text`: `with(String)`, `with(Signal<String>)` (primary `text`)
- `Image`: `with()` (no-arg, source-less — replaces `of()`), `with(String)`, `with(Signal<String>)` (primary `source`)
- `Icon`: `with(IconName)`, `with(String)`, `with(Signal<String>)` (primary `name`); KEEP `labeled(...)`
- `Label`: `with(String)`, `with(Signal<String>)` (primary `title`; icon combos use the lambda only)
- `ProgressView`: `with(float)`, `with(Signal<Float>)` (primary `value`); KEEP `indeterminate()`; remove the `progress(float)` alias
- `RoundedRectangle`: `with(float)` (primary `cornerRadius`)
- `Audio`: `with()` (no-arg), `with(String)`, `with(Signal<String>)` (primary `source`)
- `Video`: `with()` (no-arg), `with(String)`, `with(Signal<String>)` (primary `source`)
- `Shape`: `with(ShapeKind)` (primary `kind`)

Eligible — **single-value modifiers** (return the modifier; raw + Signal where both exist):
`Padding`(uniform), `FontSize`(size), `ForegroundStyle`(color), `Background`(color), `Tint`(color), `CornerRadius`(radius), `Opacity`(value), `Blur`(radius), `Rotation`(degrees), `ScaleEffect`(value), `LineLimit`(value int + Signal<Integer>), `Kerning`(value), `Tracking`(value), `BaselineOffset`(value), `LineSpacing`(value), `FontWidth`(value), `FontFamily`(family), `MinimumScaleFactor`(value), `LayoutPriority`(value), `ZIndex`(value), `ColorMultiply`(color), `ClipShape`(shape), `HueRotation`(degrees), `Saturation`(value), `Contrast`(value), `Brightness`(value), `Grayscale`(value), `AccessibilityLabel`(text), `AccessibilityRole`(role int + Signal<Integer>), `AccessibilityState`(state), `ImageSource`(source), `Visible`(visible), `Disabled`(disabled), `AllowsHitTesting`(allowed), `Underline`(enabled), `Strikethrough`(enabled), `PointerEvents`(mask), `TapGesture`(action Runnable), `Shadow`(radius).

Note `AccessibilityRole.of(int)` currently validates reserved codes (throws `IllegalArgumentException` for non-semantic codes). Move that validation into `AccessibilityRole.with(int)` (the shortcut) so `with(20)` still throws; the `with(Consumer)` path is unchanged.

## B. REMOVE `.of(...)` from EVERY view and modifier class (and all its overloads). Config-less types get an empty `with()` instead:
- `Rectangle`, `Circle`, `Capsule`, `Ellipse`, `Divider`, `Spacer`: remove `of()`; ADD `public static ViewBuilder<X, Config> with() { return new ViewBuilder<>(new X(new Config())); }` (Rectangle/Circle/Capsule/Ellipse may need a `Config` — they already implement `Configurable<Config>`).
