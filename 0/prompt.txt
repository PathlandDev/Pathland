## The v2 surface (already implemented, confirmed green)
- Views construct via static `with(Consumer<Config>)` returning `ViewBuilder` (which IS a `View`): `Text.with(t -> t.text("x"))`, `VStack.with(v -> v.alignment(HorizontalAlignment.LEADING).spacing(8f)).children(a, b)`, `Button.with(b -> b.title("t").action(() -> ...))`, `Button.with(b -> b.action(...)).children(label)`, `Grid.with(g -> g.columns(2)).children(a, b)`, `Slider.with(s -> s.value(sig).in(0f, 100f))`, `Toggle.with(t -> t.isOn(sig))`, `ProgressView.with(p -> p.value(...))`, `Picker.with(p -> p.selection(sig)).children(options)`, `DatePicker.with(d -> d.selection(days))`, etc.
- `.modifiers(mod, mod2, ...)` — applies modifier values; chainable in any order with `with(config Lambda)` and `children(...)` on the builder.
- Inner config classes are `X.Config` e.g. `Grid.Config`, `Grid.with(g -> g.columns(2).rows(3))`.
- Modifier factories: `Padding.with(p -> p.uniform(16))`, `Padding.with(p -> p.edges(t, r, b, l))`, `FontSize.with(s -> s.size(18))`, `ForegroundStyle.with(f -> f.color(color))`, `Background.with(b -> b.color(color))`, `Frame.with(f -> f.width(100f).height(24f))`, `Border.with(b -> b.color(c).width(w).radius(r))`, `Opacity.with(o -> o.value(v))`, `LineLimit.with(l -> l.value(n))`, `AccessibilityRole.with(a -> a.role(role))`, `AccessibilityLabel.with(a -> a.text(t))`, `ClipShape.with(c -> c.shape(ShapeKind))`, `Offset.with(o -> o.x(x).y(y))`, `Shadow.with(s -> s.color(c).radius(r))`, `AspectRatio.with(a -> a.ratio(r).contentMode(mode))`, `CornerRadius.with(c -> c.radius(r))`, `Blur.with(b -> b.radius(r))`, `FixedSize.with(f -> f.horizontal(true).vertical(true))`, `ImageSource.with(s -> s.source(src))`, `Kerning.with(k -> k.value(v))`, `Visible.with(v -> v.visible(flag))`, `Disabled.with(d -> d.disabled(b))`, `AllowsHitTesting.with(a -> a.allowed(b))`, `Underline.with(u -> u.enabled(b))`, etc.
