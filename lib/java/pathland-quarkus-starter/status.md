# pathland-quarkus-starter — implementation status

**Last updated:** November 1, 2026

**Deprecated compatibility alias.** This module is no longer a Quarkus runtime
integration; it only depends on `pathland-quarkus-java` so existing
`pathland-quarkus-starter` consumers keep the previous "starter + Java DSL"
behavior.

Use one of:

- `pathland-quarkus` — DSL-neutral Quarkus extension
- `pathland-quarkus-java` — Java DSL extension
- `pathland-quarkus-kotlin` — Kotlin DSL extension

The alias remains until the Java DSL is retired.
