# pathland-view

A SwiftUI-style, `no_std` view DSL — `VStack`/`HStack`/`Text`/`Button` and
chainable modifiers — that builds the retained tree (`pathland_engine::Node`)
the emitter consumes.

Part of [Pathland](https://github.com/PathlandDev/Pathland). Depends on
[`pathland-core`](https://crates.io/crates/pathland-core) and
[`pathland-engine`](https://crates.io/crates/pathland-engine).
