# pathland-render-html

The HTML renderer: a stateless, streaming pure function of the opcode stream
that maps declarative frames onto HTML elements — Pathland's server-side /
remote-projection target.

Part of [Pathland](https://github.com/PathlandDev/Pathland). Depends on
[`pathland-core`](https://crates.io/crates/pathland-core) and
[`pathland-core-transport`](https://crates.io/crates/pathland-core-transport).
