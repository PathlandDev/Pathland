# pathland-core-transport

The transport layer for Pathland's opcode stream: the zero-copy shared-memory
SPSC ring, the network batch encoder/decoder, and the time/size batching policy.

Part of [Pathland](https://github.com/PathlandDev/Pathland). Depends on
[`pathland-core`](https://crates.io/crates/pathland-core).
